## 🆘 常见问题

**Q：改好后怎么看效果？**
A：重新打开或刷新 chat.html，然后搜索知识库，应该能看到详细的分数和分类信息。

**Q：有错误怎么办？**
A：
1. 打开浏览器开发者工具 (F12)
2. 查看 Console 标签是否有红色错误
3. 检查函数名是否拼写正确
4. 确认 API 返回的 JSON 字段完整

**Q：可以跳过这个改造吗？**
A：从技术上可以，但用户看不出后端的改进。建议完成改造，这样用户能体验到 Dense Vector 的优势。

**Q：改造需要后端改变吗？**
A：不需要。后端已经完全支持，返回所有必要的 JSON 字段。

**Q：如何推送到服务器？**
A：改造完后，将 `frontend/` 文件夹上传/部署到服务器即可。
