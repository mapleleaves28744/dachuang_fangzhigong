### 根本原因 🔍
✅ 后端已升级到 FAISS Dense Vector 检索
❌ 前端仍显示简陋的纯文本结果，用户看不出改进

### 改造目标 🎯
让用户能够**看到、感受到**后端的改进：
- 看到分数构成（向量/词法/综合）
