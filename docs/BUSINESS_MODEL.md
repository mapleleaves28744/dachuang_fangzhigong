## 2. 商业模式

### 2.1 收入流结构

```
FZG 收入 = B2B学校端 + B2C学生端 + B2B2C渠道
         = $1.2M + $2.1M + $0.8M
         = $4.1M (Year 1预期)
```

#### 2.1.1 B2B学校端（45% 收入 = ~$1.84M）

**模式**：按年购买学校合作方案  
**定价**：

| 学校规模 | 学生数 | 年费用 | 单生成本 |
|---------|-------|--------|---------|
| 小型(1-3个班) | 100-300人 | ¥8K-15K | ¥40-50/生 |
| 中型(5-10个班) | 300-1000人 | ¥25K-50K | ¥25-50/生 |
| 大型(15+个班) | >1000人 | ¥80K-150K | ¥15-30/生 |

**目标**：1年内与50所学校合作 → ¥1.84M收入

#### 2.1.2 B2C学生端（40% 收入 = ~$1.64M）

**模式**：SaaS订阅 + 按题付费  

**订阅方案**：
| 套餐 | 月费 | 功能 | 用户预期 |
|------|------|------|---------|
| **Free** | ¥0 | 5题/月限制，基础诊断 | 30K |
| **Pro** | ¥29 | 无限题目，完整掌握度跟踪 | 8K (转化率 26%) |
| **Premium** | ¥79 | 1v1查疑+学习规划，优先支持 | 1K (转化率 12.5%) |

**收入计算**（年度）：
- Free → Pro转化：30K × 26% × ¥29 × 12 = ¥27.1M ❌ **过高**
- 重新调整：目标8K Pro用户 = 8K × ¥29 × 12 = ¥2.78M
- 其中Free比例50% → **¥1.39M Pro收入** + **¥0.25M Premium** ≈ **¥1.64M**

#### 2.1.3 B2B2C渠道（15% 收入 = ~$0.6M）

**模式**：与教育课程平台合作（如网易云课堂、腾讯课堂）

**合作对象**：
- 在线直播教学平台 → 嵌入FZG作为陪学工具
- 拆分模式：平台20% + FZG 80%
- 目标：签约3-5个中型平台 → ¥600K收入

## 4. 定价策略

```

月费¥29    预计用户8K     收入¥0.28M/月  ⭐ 推荐
```

## 5. 投资回报（ROI）

### 5.1 投资场景

**种子-天使轮融资目标** = ¥2-3M

**用途分配**：
- 产品研发 + 技术债：¥1.2M (40%)
- 市场推广 + BD：¥0.8M (27%)
- 人员扩建 + 福利：¥0.6M (20%)
- 储备资金：¥0.4M (13%)

### 5.2 资金消耗率与跑道

```
月烧钱率(Year 1) = (成本 - 收入) / 12
                = (4.644M - 4.1M) / 12 
                = ¥45K/月

融资¥2.5M / ¥45K = 55个月跑道 ✅ 足够到盈利
```

### 5.3 退出价值评估

**假设到Year 3**：
- 用户数：10万（付费转化15%）
- 年收入：¥14.5M
- 行业估值倍数：5-7x营收（对标教育科技企业）

**评估值** = ¥14.5M × 6x = **¥87M** → IPO前估值

**投资者回报**：
- 初始投资¥2.5M占股 ~3%（pre-money估值¥80M）
- IPO时价值 = 2.5M × (¥87M / ¥80M) = **¥2.7M** 
- 回报率 = 2.7M / 2.5M = **1.08x** ❌ 偏低

**优化方案**：
- 瞄准更激进的营收增长（Y3达¥25-30M）
- 评估值提升到¥150-180M → 投资者10x回报 ✅
